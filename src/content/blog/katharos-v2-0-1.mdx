MonoPanel **Katharos V2.0.1** is a stable release. This post is a short tour of what it is made of, so you know what you are installing.

## One platform, two parts

The **panel** is the website, customer accounts, billing, support desk, mail inbox and admin panel. The **daemon** is a small agent you run on every node. The panel only ever talks to a daemon with signed requests, so adding capacity means adding a node and running one command.

## Bot hosting and VPS hosting

Customers create servers from the software you offer. Node.js, Python, a static website and Minecraft (Paper) ship by default. Every server has RAM, CPU, swap, disk and process limits, a live console, a file manager with a recycle bin, backups, scheduled tasks, team access and node switching, as far as the customer's plan allows.

VPS hosting runs on the same daemon. Each VPS is a Docker container with SSH, Docker, Node.js and pm2, and customers choose Ubuntu 22.04, Ubuntu 24.04 or Debian 12.

## PostgreSQL only

The panel and the daemon both store their state in PostgreSQL 12 or newer. There is no embedded SQLite mode and no JSON database file, so what you back up is one real database per component.

```bash
npm run db:info   # shows which database the panel uses (stop the panel first)
```

## Signed, not trusted

Every request from the panel to a daemon carries a timestamp, a single-use nonce and an HMAC-SHA256 signature. Requests older than 60 seconds and replayed nonces are refused, and you can restrict each daemon to your panel's IP address.
