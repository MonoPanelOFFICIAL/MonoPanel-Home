The panel lives at [MonoPanelOFFICIAL/MonoPanel-Panel](https://github.com/MonoPanelOFFICIAL/MonoPanel-Panel) and the daemon at [MonoPanelOFFICIAL/MonoPanel-daemon](https://github.com/MonoPanelOFFICIAL/MonoPanel-daemon). The workflow is: fork the repository, clone your fork, create a branch named `future`, make your change, test it, push and open a pull request.

```bash
git clone https://github.com/<your-username>/MonoPanel-Panel.git
cd MonoPanel-Panel
git checkout -b future
npm install
cp .env.example .env
```

Set `JWT_SECRET`, `MONOPANEL_ADMIN_EMAIL`, `MONOPANEL_ADMIN_PASSWORD` and `DATABASE_URL` in `.env`, then:

```bash
npm run dev      # start the dev server on http://localhost:3000
npm run lint     # type-check, must pass
npm run build    # production build
```

Never work directly on `main`. See `CONTRIBUTING.md` in the panel repository for the full guide.
