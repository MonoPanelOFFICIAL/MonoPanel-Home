The console shows the server's log and lets you send commands.

## How it works

The browser never talks to the node. It asks the panel for `/api/v1/hosting/servers/:id/console`, and the panel opens the node's log stream and passes it on as **server-sent events**. This keeps node addresses and secrets private. Commands go through the panel too.

The console starts with the last 200 log lines, then streams new output as it appears. Each user can open at most 20 console connections per minute.

## Permissions

| Action | Permission needed |
|---|---|
| Watch the console | `console.read` |
| Send commands | `console.command` |

The owner has both. Team members only get what the owner grants.
