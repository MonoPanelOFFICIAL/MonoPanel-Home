Scheduled tasks are available on plans that include the scheduled tasks feature.

## A schedule

A schedule has a name, a cron expression, an enabled switch and **one to six tasks** that run in order. Each task can wait up to 120 seconds before it runs.

| Task | Payload |
|---|---|
| `command` | A single-line console command, up to 500 characters |
| `power` | One of `start`, `stop`, `restart` or `kill` |
| `backup` | None. Needs at least one backup slot on the server |

## Limits

The number of schedules per server is set by the plan's `schedules` limit.

The plan is checked when a schedule is created and again every time it fires, so if a plan lapses the automation simply pauses and returns when the plan does.

Team members need the `schedules` permission.
