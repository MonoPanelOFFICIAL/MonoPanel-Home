MonoPanel has an optional economy for free and entry-level plans.

## Coins

Coins are tracked in a ledger, so every change records the reason and the balance afterwards. Customers can earn coins, claim a daily reward and spend them in the coin store or on addons. Admins can adjust a user's coins and see the ledger.

## Renewal methods

A plan lists which methods can renew a server: `ads`, `blog`, `coins` or `payment`. The shipped free plan renews every 7 days with ads or blog views, and the shipped Premium plan renews with payment or coins. Renewal extends from whichever is later, now or the current expiry, so renewing early never loses time.

## Reminders

The panel sends a reminder before a server expires. After expiry the server is stopped, and 24 hours later it is deleted if not renewed.
