## Addons

An addon is a set of files downloaded onto a server. Admins define each addon with:

- a name, category, description and icon,
- the software it works with (or all software),
- a list of files, each with a source URL, a destination path and whether to extract it,
- an optional command to run afterwards, and whether to restart the server,
- a price in coins, in account credits, or free.

Customers install addons from their server page. The install is charged first, then the node downloads the files, and the charge is **refunded automatically if the node fails**. An addon can be installed on a server only once, and not while the server is suspended, expired, installing, install failed or transferring. Team members need the `addons` permission.

Addon downloads on the daemon are guarded against private network addresses.

## Coin store

The store sells upgrades paid in coins, for example extra RAM or CPU for 7 days, permanent extra disk, a server renewal, temporary Premium, an extra server slot and boosted servers. Items and prices are set by the admin and ship with defaults you can change.
