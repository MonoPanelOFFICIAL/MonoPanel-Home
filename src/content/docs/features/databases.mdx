Each server has a Databases tab where customers can create databases, limited by the plan's `databases` setting.

## Setup

Point the panel at a MySQL or MariaDB host with these variables in `.env`:

```env
DB_HOST_ADDRESS=""
DB_HOST_PORT="3306"
DB_HOST_ADMIN_USER=""
DB_HOST_ADMIN_PASSWORD=""
```

The admin account must be allowed to `CREATE DATABASE`, `CREATE USER` and `GRANT`. Leave `DB_HOST_ADDRESS` empty to hide database creation entirely. If customers should connect to a different address than the panel does, set `DB_HOST_PUBLIC_ADDRESS` and `DB_HOST_PUBLIC_PORT`.

## Credentials

Customers can rotate a database's password from the server page.

This MySQL or MariaDB host is separate from the PostgreSQL database that MonoPanel itself uses.
