| Module | Responsibility |
|---|---|
| `server/hosting/serverService.ts` | Server creation, limits, port allocation, pushing specs to nodes |
| `server/hosting/plans.ts` | Plans, features and effective plan per user |
| `server/hosting/access.ts` | Owner and team access resolution |
| `server/hosting/daemonClient.ts` | Signed requests to daemons |
| `server/hosting/schedules.ts`, `cron.ts` | Cron schedules and task execution |
| `server/hosting/transfer.ts` | Node switching |
| `server/hosting/addons.ts` | Addon installs, charging and refunds |
| `server/hosting/lifecycle.ts` | Expiry and deletion policy |
| `server/hosting/coins.ts` | Coin ledger |
| `server/hosting/databases.ts` | MySQL or MariaDB databases per server |
| `server/vps/service.ts` | VPS provisioning and operations |
| `server/discordService.ts` | Discord bot and notifications |
| `server/webhookService.ts` | Signed webhook delivery |
| `server/services/provisioningService.ts` | Optional auto-provisioning on a Pterodactyl or Pelican-compatible panel (off by default) |
