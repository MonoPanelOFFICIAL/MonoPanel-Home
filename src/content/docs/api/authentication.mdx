The panel API lives under `/api/v1/`.

## Sessions

Browsers sign in with email and password, or with Google or Discord, and receive a JSON Web Token kept in the `monopanel_token` cookie. The token can also be sent as `Authorization: Bearer <token>`.

## API keys

Admins create keys under **Admin → REST API Keys**. A key can have:

- a name and description,
- **scopes** (`*` for everything, or specific ones such as `users.read`, `users.manage` and `orders.read`),
- an optional IP allow-list,
- an expiry (a number of days, or a custom date).

Send a key in the `x-api-key` header or as a bearer token. A key is limited to 60 requests per minute. Keys can be revoked, rotated and deleted, and every use is written to the API audit log.

```bash
curl https://your-panel/api/v1/... -H "x-api-key: <your key>"
```

## Panel to daemon

The panel signs every daemon request with HMAC-SHA256. That is not something API users do, but it is documented in [Daemon security](/docs/daemon/security/).
