A webhook subscription has a URL, a secret and a list of events (`*` means all).

## Delivery

The panel sends a `POST` with a JSON body and these headers:

| Header | Content |
|---|---|
| `X-MonoPanel-Event` | Event name |
| `X-MonoPanel-Signature-256` | `sha256=` followed by the hex HMAC-SHA256 of the body, using the webhook secret |
| `X-MonoPanel-Delivery` | Unique delivery id |
| `User-Agent` | `MonoPanel-Webhook-Delivery/1.0` |

Deliveries time out after 10 seconds, and any 2xx response counts as success. The panel records the last status and error for each webhook.

## Verifying

```js
import crypto from "node:crypto";

function verify(rawBody, header, secret) {
  const expected =
    "sha256=" + crypto.createHmac("sha256", secret).update(rawBody).digest("hex");
  return crypto.timingSafeEqual(Buffer.from(expected), Buffer.from(header));
}
```

## Safety

The webhook URL must resolve to public addresses only, and the resolved address is pinned for the request, so a webhook cannot be used to reach internal services. You can send a test delivery, toggle and delete webhooks from the panel.
