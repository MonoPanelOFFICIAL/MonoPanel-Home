Everything lives under `/api/v1/`.

| Namespace | Purpose |
|---|---|
| `auth`, `account` | Sign-up, login, OAuth and account settings |
| `public`, `plans` | Public site data such as plans and branding |
| `billing` | Orders, credits and coupons |
| `support` | Tickets |
| `mail` | Inbox and broadcasts |
| `economy` | Coins, daily rewards and the coin store |
| `hosting`, `hosting-public` | Customer server operations and public hosting data |
| `vps` | Customer VPS operations |
| `ads` | Ad campaigns |
| `discord` | Discord linking and integration |
| `status` | Incidents and maintenance |
| `api-keys` | REST API keys and webhooks |
| `admin` | Admin panel operations |
| `admin/hosting`, `admin/vps`, `admin/manager-bot` | Hosting, VPS and Discord manager bot administration (admin and super admin only). `admin/hosting/kinds` reads and saves the enabled hosting types |

Stripe delivers payment events to `POST /api/v1/stripe/webhook`, which verifies Stripe's signature on the raw request body.

Hosting types that are switched off answer `404` or `403` with the code `HOSTING_DISABLED`. Per-server tools live under `hosting/servers/:id/` (`lavalink`, `nodejs` and `site`). Responses are JSON.

## API keys and webhooks (`/api/v1/api-keys`)

| Method | Path | Purpose |
|---|---|---|
| GET | `/dashboard` | Key statistics |
| GET | `/audit-logs` | API audit log |
| GET | `/` | List keys |
| POST | `/` | Create a key |
| POST | `/:id/revoke` | Revoke a key |
| POST | `/:id/rotate` | Rotate a key |
| DELETE | `/:id` | Delete a key |
| GET | `/webhooks/list` | List webhooks |
| POST | `/webhooks/create` | Create a webhook |
| POST | `/webhooks/:id/test` | Send a test delivery |
| PATCH | `/webhooks/:id/toggle` | Enable or disable |
| DELETE | `/webhooks/:id` | Delete |

The key management endpoints need an admin session.
