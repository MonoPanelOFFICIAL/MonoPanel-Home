Every VPS is one Docker container built from the ROM in `rom/`: Ubuntu or Debian with sshd, Docker, Node.js, pm2 and build tools. The first create builds the image, which takes a few minutes. Set `VPS_PREBUILD_OS=ubuntu-22.04` to build it at daemon start instead.

| Setting | Meaning |
|---|---|
| `VPS_RUNTIME` | `auto` (on when Docker answers), `docker` (required), `mock` (development only) or `off` |
| `VPS_OCI_RUNTIME` | `sysbox-runc` lets customers run Docker inside their VPS safely. Recommended |
| `VPS_PRIVILEGED` | Alternative to Sysbox. **Insecure:** a VPS root user can escape to the host |
| `VPS_ALLOWED_BASE_PREFIXES` | Base images the panel may request. Default `ubuntu:,debian:` |
| `VPS_PREBUILD_OS` | OS ids to build at start, for example `ubuntu-22.04,debian-12` |

Container names are `monovps-<id>` and carry the `monovps=1` label, kept from the old VPS daemon so existing VPSes keep working.

## Routes

| Method | Path | Purpose |
|---|---|---|
| GET | `/v1/vps` | List VPSes |
| POST | `/v1/vps` | Create |
| GET | `/v1/vps/:id` | Stats |
| DELETE | `/v1/vps/:id` | Destroy |
| POST | `/v1/vps/:id/power` | Power action |
| POST | `/v1/vps/:id/resize` | Change limits |
| GET | `/v1/vps/:id/logs` | Logs |
| POST | `/v1/vps/:id/exec` | Run a command |
| GET, PUT | `/v1/vps/:id/file` | Read, write a file |
| GET | `/v1/vps/:id/files` | List files |
| POST | `/v1/vps/:id/mkdir`, `/delete`, `/rename` | File operations |
| POST | `/v1/vps/:id/password` | Set the root password |
| GET, POST | `/v1/vps/:id/sshx` | Status, start or stop sshx |
