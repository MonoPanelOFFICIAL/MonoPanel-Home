Set `SFTP_PORT` (or pass `--sftp 2022` to `configure`) and run `npm install`, which installs the optional `ssh2` package. Without `ssh2`, the daemon logs a warning and runs without SFTP. Open the port to customers, and set the node's `sftpPort` in the panel.

## Logging in

Users log in as `<panel-username>.<server-id8>` with the password they create in the server's Settings tab. The panel stores a scrypt hash of that password and the daemon verifies it.

## Isolation

- A login only ever sees one server's files.
- Symlinks are not followed.
- Writes respect the disk quota.
- Shell and exec are refused.

The host key defaults to `data/sftp_host_key.pem`, or set `SFTP_HOST_KEY`. Team members need the `sftp` permission.
