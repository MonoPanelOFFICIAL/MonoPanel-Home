Put the panel behind a reverse proxy for HTTPS, and set `APP_URL` and `ALLOWED_ORIGINS` to your public domain.

## Nginx

```nginx
server {
    listen 80;
    server_name your-domain.com;
    return 301 https://$host$request_uri;
}

server {
    listen 443 ssl http2;
    server_name your-domain.com;

    # ssl_certificate / ssl_certificate_key via certbot

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

The live console streams over server-sent events. If you proxy with Nginx, keep response buffering off for that route (the panel already sends `X-Accel-Buffering: no`).

## Caddy

```caddy
your-domain.com {
    reverse_proxy 127.0.0.1:3000
}
```

## Trusted proxies

Set `TRUST_PROXY` to the number of proxies in front of the panel: `1` for Nginx or Caddy, `2` for Cloudflare plus Nginx, or `false` if there is no proxy. The panel uses the resulting client address for rate limits and bans, so a wrong value lets clients spoof their IP.

## systemd

```ini
# /etc/systemd/system/monopanel.service
[Unit]
Description=MonoPanel
After=network.target

[Service]
WorkingDirectory=/opt/monopanel-panel
ExecStart=/usr/bin/npm start
Restart=always
Environment=NODE_ENV=production
User=monopanel

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now monopanel
```

## PM2

```bash
npm i -g pm2
npm run build
pm2 start npm --name monopanel -- start
pm2 save && pm2 startup
```

## Daemon service

Run each daemon as a dedicated unprivileged user (add it to the `docker` group when using Docker):

```ini
[Service]
User=monopanel
WorkingDirectory=/opt/monopanel/daemon
ExecStart=/usr/bin/node dist/index.js
Restart=always
NoNewPrivileges=true
```

## Backups

Back up PostgreSQL on a schedule with `pg_dump`, point-in-time recovery or your provider's snapshots. The admin panel can also run `pg_dump` for you under **Admin → Hosting → Database**, which needs the `postgresql-client` package on the panel machine.
